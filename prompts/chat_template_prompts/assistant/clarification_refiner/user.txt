## Guidelines
- Output a single line with the comma-space-separated names of parameters still requiring clarification.
- The first element of the dialogue history should be used to determine the current datetime for disambiguation of any temporal parameters.
- If no parameters require clarification, output `N/A`.
- Avoid any extra punctuation, explanation, or formatting around the output.

---
